# Science Museum Group (science-museum-group)
The Science Museum Group Collection API provides programmatic access to the museum's extensive collection of science, technology, and cultural artifacts. The API enables developers to search, browse, and retrieve data about objects, people, and events from the Science Museum Group's collections across its five UK museums.
